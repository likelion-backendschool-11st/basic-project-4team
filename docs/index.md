# 길잡이 (파일 안내)

AI와 사람이 필요한 파일을 바로 찾기 위한 목차. 새 파일·폴더를 만들면 한 줄 추가한다.

| 찾는 것 | 위치 | 설명 |
|---|---|---|
| 합격 기준 | `SPEC.md` | 현재 작업의 목표와 검사 명령 |
| 작업 상태 | `PROGRESS.md` | 완료 / 남은 일 / 다음 시작 위치 |
| 판정기 | `scripts/verify.py` | SPEC의 `cmd:` 실행 |
| 테스트 | `tests/` | 승인 후 잠김 |
| (소스 진입점) | (예: `src/main.py`) | |

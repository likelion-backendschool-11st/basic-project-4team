- SPEC·tests는 잠겨 있어 테스트 DB 이름이나 방식을 바꿀 수 없음

## 사람이 할 일
```
docker exec mysql1 sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "GRANT ALL PRIVILEGES ON \`repick_schema_test\`.* TO '\''repick'\''@'\''%'\'';"'
```
- 범위: `repick_schema_test` DB만. 되돌리기: `REVOKE ALL PRIVILEGES ON ... FROM ...`
- 실행 후 AI에게 "권한 줬어"라고 알려 주면 verify를 다시 실행한다.

## 사람이 할 일 (둘 중 하나)
1. 로컬 MySQL 8을 설치하거나 실행한다. `backend/.env`의 DB_HOST·DB_PORT·DB_USER·DB_PASSWORD로 접속할 수 있어야 한다.
2. Docker Desktop을 켜고 MySQL 8 컨테이너를 띄운다:
   `docker run -d --name repick-mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=<.env의 DB_PASSWORD> mysql:8.0`

준비되면 AI에게 "MySQL 켰어"라고 알려 주면 verify를 다시 실행한다.
